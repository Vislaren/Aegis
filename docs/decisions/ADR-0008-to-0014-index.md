# ADRs 0008 to 0014: decisions planned for later phases

These ADRs are required by the build prompt. Only ADR-0014 is written so far; the others are planned, with direction recorded below. Each must be completed before its phase is marked done.

| ADR  | Topic                 | Phase                     | Direction recorded now                                                                                                                                                                                                      |
| ---- | --------------------- | ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 0008 | Offline sync          | 3                         | SQLite outbox on the device; client UUID and per-device sequence; server unique `client_uuid`; safety events before GPS batches; explicit conflict states, never last-write-wins.                                           |
| 0009 | Transport event model | 3                         | Append-only `TransportEvent` in trip-service; projections updated transactionally; corrections reference the original event.                                                                                                |
| 0010 | Realtime              | 1 (privileged channel), 4 | realtime-gateway authorizes every subscription through the owning service and revalidates periodically. School and trip rooms are added in Phase 4. Redis adapter when scaled out.                                          |
| 0011 | Notifications         | 5                         | notification-service is driven only by accepted events. Recipients are resolved at send time. Deduplication key is (event, recipient, channel, template version). Push first, SMS or WhatsApp fallback for critical events. |
| 0012 | Map provider          | 4                         | MapLibre with a contracted tile provider. Never public OpenStreetMap tiles in production.                                                                                                                                   |
| 0013 | Retention             | 6                         | Configurable per category in `school_settings`; scheduled deletion with deletion reports; audit and journal retained under the legal hold policy.                                                                           |
| 0014 | Deployment            | 0                         | See [ADR-0014-deployment.md](ADR-0014-deployment.md).                                                                                                                                                                       |

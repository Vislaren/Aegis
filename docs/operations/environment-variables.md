# Environment variable reference

No values are committed. Local development values are generated by `node scripts/setup-dev-env.mjs` into git-ignored files. Deployed environments read secrets from the managed secret store, with one secret set per service.

## Sensitivity and rotation

| Sensitivity | Meaning                                                   |
| ----------- | --------------------------------------------------------- |
| **S**       | Secret                                                    |
| **C**       | Confidential, such as connection strings with credentials |
| **P**       | Public configuration                                      |

Rotation methods:

| Rotation | Method                                                                |
| -------- | --------------------------------------------------------------------- |
| R1       | Rotate in the secret store, then do a rolling restart.                |
| R2       | Two-phase key rotation. See [key rotation](runbooks/key-rotation.md). |
| R3       | Change through configuration review only.                             |

## All services

| Variable                      | Purpose                                                                                        | Sensitivity | Example shape                                                    | Rotation |
| ----------------------------- | ---------------------------------------------------------------------------------------------- | ----------- | ---------------------------------------------------------------- | -------- |
| `NODE_ENV`                    | `development`, `test`, `staging`, or `production`. Deployed values enable the safety refusals. | P           | `production`                                                     | R3       |
| `PORT`                        | HTTP listen port                                                                               | P           | `3002`                                                           | R3       |
| `LOG_LEVEL`                   | pino level                                                                                     | P           | `info`                                                           | R3       |
| `OTEL_EXPORTER_OTLP_ENDPOINT` | Enables tracing when set                                                                       | P           | `https://otel.internal:4318`                                     | R3       |
| `SERVICE_NAME`                | Service identity used in service tokens                                                        | P           | `administration-service`                                         | R3       |
| `SERVICE_PRIVATE_KEY`         | This service's ES256 private JWK for service tokens                                            | S           | `{"kty":"EC",...,"d":"..."}`                                     | R2       |
| `TRUSTED_SERVICE_KEYS`        | Public JWKs of allowed callers                                                                 | P           | `{"audit-service":{"kty":"EC",...}}`                             | R2       |
| `ACCESS_TOKEN_ISSUER`         | Expected `iss` of access tokens                                                                | P           | `https://identity.aegis.example`                                 | R3       |
| `IDENTITY_JWKS_URL`           | identity-service JWKS (internal)                                                               | P           | `http://identity-service:3001/internal/v1/.well-known/jwks.json` | R3       |
| `AMQP_URL`                    | RabbitMQ. Must be `amqps://` when deployed.                                                    | C           | `amqps://user:pass@mq.internal:5671`                             | R1       |
| `BROKER`                      | `rabbitmq` (`memory` is refused when deployed)                                                 | P           | `rabbitmq`                                                       | R3       |

## Database URLs

| Variable                 | Purpose                                                                                                             | Sensitivity | Example shape                                                      | Rotation |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------- | ----------- | ------------------------------------------------------------------ | -------- |
| `DATABASE_URL`           | Runtime role `<service>_app`. Not the owner and no BYPASSRLS. Used by identity, administration, and audit services. | C           | `postgresql://administration_app:...@db:5432/aegis_administration` | R1       |
| `MIGRATION_DATABASE_URL` | Owner role, for the one-shot migration task only                                                                    | C           | `postgresql://administration_owner:...@db/aegis_administration`    | R1       |

## identity-service

| Variable                           | Purpose                                                             | Sensitivity | Rotation                              |
| ---------------------------------- | ------------------------------------------------------------------- | ----------- | ------------------------------------- |
| `ACCESS_TOKEN_SIGNING_KEY`         | ES256 private JWK with `kid`                                        | S           | R2                                    |
| `ACCESS_TOKEN_PREVIOUS_PUBLIC_KEY` | Previous public JWK, published during rotation                      | P           | R2                                    |
| `ACCESS_TOKEN_TTL_SECONDS`         | Default 300; must be ≤ 600 when deployed                            | P           | R3                                    |
| `OTP_PEPPER`                       | HMAC key for one-time codes and device IDs. At least 32 characters. | S           | R1 (outstanding codes become invalid) |
| `MFA_ENCRYPTION_KEY`               | AES-256-GCM key for TOTP secrets: 32 bytes, base64                  | S           | R2 (re-encrypt job required)          |
| `DELIVERY`                         | `smtp` or `memory` (`memory` is refused when deployed)              | P           | R3                                    |
| `SMTP_URL`                         | Email transport. Mailpit locally; refused when deployed.            | C           | R1                                    |
| `MAIL_FROM`                        | Sender address                                                      | P           | R3                                    |
| `APP_PUBLIC_URL`                   | Base URL for invitation links                                       | P           | R3                                    |
| `COOKIE_SECURE`                    | Must be `true` when deployed                                        | P           | R3                                    |

## administration-service

| Variable                     | Purpose                                                | Sensitivity | Rotation                |
| ---------------------------- | ------------------------------------------------------ | ----------- | ----------------------- |
| `IDENTITY_INTERNAL_URL`      | identity-service internal base URL                     | P           | R3                      |
| `LEASE_HEARTBEAT_SECONDS`    | Default 60                                             | P           | R3 (journal the change) |
| `LEASE_TTL_SECONDS`          | Default 300; must be at least 2 × heartbeat            | P           | R3                      |
| `LEASE_IDLE_TIMEOUT_SECONDS` | Default 900; must be at least the TTL                  | P           | R3                      |
| `MFA_FRESHNESS_SECONDS`      | Default 300; applies to takeover and forced revocation | P           | R3                      |

## audit-service and realtime-gateway

| Variable                      | Service           | Purpose                                              |
| ----------------------------- | ----------------- | ---------------------------------------------------- |
| `ADMINISTRATION_INTERNAL_URL` | audit, realtime   | Lease validation                                     |
| `IDENTITY_INTERNAL_URL`       | realtime          | Session introspection                                |
| `ALLOWED_ORIGINS`             | realtime, gateway | Comma-separated origins; must be HTTPS when deployed |
| `REVALIDATE_INTERVAL_SECONDS` | realtime          | Privileged subscription revalidation (default 30)    |

## api-gateway

| Variable                                                          | Purpose                                               |
| ----------------------------------------------------------------- | ----------------------------------------------------- |
| `IDENTITY_URL`, `ADMINISTRATION_URL`, `AUDIT_URL`, `REALTIME_URL` | Upstream base URLs                                    |
| `RATE_LIMIT_PER_MINUTE`, `AUTH_RATE_LIMIT_PER_MINUTE`             | Per-IP limits (defaults 300 and 20)                   |
| `PUBLISH_OPENAPI`                                                 | Serves `/api/v1/openapi.json`. Refused in production. |

## Tests

| Variable                  | Purpose                                                               |
